# CodeCanyon launch checklist — LuxeFind Search Pro

The **installable plugin ZIP** is separate from the **buyer package ZIP** containing documentation.

## Blocking gates (not yet signed off)

- [ ] Install plugin in pristine WordPress 6.2+, 6.6+, current version and supported PHP 8.1–8.4 environment.
- [ ] OPTIONAL feature: If advertising WooCommerce support, install on WooCommerce and test product filters/SKU/visibility; core metasearch release does not require WooCommerce.
- [ ] Verify the Gutenberg block and legacy shortcode across Twenty Twenty-Five + one widely used commercial theme.
- [ ] Verify plugin checks/WordPress coding standards/Envato latest requirements; eliminate relevant warnings, don't hide errors.
- [ ] Exercise Brave live quota plans for web/image/news/videos and document supported subscription tier.
- [ ] Validate optional Mojeek integration against its exact current API contract before listing support as GA.
- [ ] Confirm Wikipedia/Nominatim/LibreTranslate current terms, API quotas, privacy disclosures and attribution.
- [ ] Validate security: REST rate limits, reflected/stored XSS, SSRF, permission/nonce checks, safe public content selection.
- [ ] Test desktop/mobile responsive UI in modern Chrome, Firefox and Safari; screen-reader + reduced motion QA.
- [ ] Benchmark cold/warm query latency, caching and database load under concurrent search traffic.
- [ ] FINALIZE UNIQUE BRAND: Public search found a US LUXEFIND trademark filing (Serial 98807368; apparel accessories category), which does not alone determine software conflict. Obtain qualified trademark clearance before commercial listing, and settle product author identity/copyright notices.
- [ ] Create buyer-ready screenshots, live public demo, item description, update/changelog policy and support documentation.
- [ ] Review the plugin's GPLv3-or-later licensing with the intended CodeCanyon item/license choice; confirm no original Seurch code has been copied.
- [ ] Submit to Envato, respond to review feedback. Acceptance is never guaranteed.

## Suggested pitch (truthful in current RC)

**Premium WordPress metasearch with opt-in external web discovery.** An elegant dark/gold search interface for blog posts, pages and WooCommerce products. Configure a secure server-side Brave Search key to add web/media tabs. No Python backend required for the plugin itself.

Avoid marketing it as a full Google alternative, AI-powered semantic search, typo-tolerant engine, guaranteed private search, complete Seurch port, unlimited API calls or production-certified yet.

## Suggested launch target (not verified market research)

Initial price hypothesis: $39–$59 regular license, subject to competitor review and current Envato fee structure. API costs, taxes, refund liability and user support are separate.
