01 — Installation

  1. In WordPress dashboard go to Plugins → Add New → Upload Plugin.
  2. Choose plugin/luxefind-search-pro.zip from your extracted buyer package.
  3. Install and activate; open Settings → LuxeFind Search.
  4. Select your searchable published content types and optional providers.
  5. Add the Gutenberg LuxeFind Premium Search block or shortcode.

The core site search runs on standard WordPress PHP hosting. It does not install Python, Django, a crawler or its own database server.

02 — Embed the search interface

[luxefind_search]
[luxefind_search mode="site"]
[luxefind_search mode="products"]

Alternative: in the Gutenberg editor insert the LuxeFind Premium Search block and select the default category and placeholder.

WooCommerce filters appear only when WooCommerce is activated and the relevant option is enabled. The REST endpoint is /wp-json/luxefind/v1/search.

03 — Optional external providers

Keep credentials in wp-config.php, never HTML/JavaScript or shortcode content:

define('LFXSP_BRAVE_API_KEY', 'YOUR_BRAVE_KEY');
// Experimental; confirm current Mojeek API terms:
define('LFXSP_MOJEEK_API_KEY', 'YOUR_MOJEEK_KEY');
// Optional public HTTPS LibreTranslate service:
define('LFXSP_LIBRETRANSLATE_URL', 'https://translate.example.org');

Once keys are configured, enable relevant providers under Settings. External modes can incur API charges; quota and endpoints vary by subscription.

05 — Privacy and safe deployment

Local search does not call external providers. If external features are activated, submitted queries may leave your server for Brave, Mojeek, Wikimedia, Nominatim or LibreTranslate, and image previews may fetch third-party content in the visitor browser. Leave the visitor notice enabled. Optional aggregate analytics only stores daily counts, not raw query strings.

The built-in transient rate limit is a best-effort safeguard, not a replacement for a shared WAF/Redis limiter on high-volume public sites.

06 — Troubleshooting

No site results: ensure posts are published and selected as searchable. No product tab: install/activate WooCommerce. API unconfigured: set the key as a PHP constant. Quota errors: review your provider plan. Stale results: click Clear cached results in the settings panel.
